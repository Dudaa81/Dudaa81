# 🚀 Projeto em destaque

<div align="center">

## 💍 Loja de Pratas — TCC

</div>

Projeto desenvolvido como **Trabalho de Conclusão de Curso**, com foco na criação de um sistema web para uma loja de pratas.

O projeto envolve funcionalidades como:

- 🛍️ Catálogo de produtos
- 🛒 Carrinho de compras
- 📦 Pedidos
- 👤 Área administrativa
- 🗄️ Banco de dados
- ♿ Recursos de acessibilidade
- 💻 Interface web

### 🧰 Tecnologias utilizadas

`PHP` `Laravel` `JavaScript` `HTML` `CSS` `Bootstrap` `MySQL`
