## ✦︎ Sobre mim

Olá! Eu sou **Maria Eduarda**, estudante de **Desenvolvimento de Sistemas** e tenho interesse principalmente pela área de **desenvolvimento web**.

Durante minha formação, venho construindo meus conhecimentos através de estudos e projetos práticos, buscando entender não apenas como escrever código, mas também como desenvolver sistemas organizados, funcionais e com uma boa experiência para o usuário.

Tenho experiência acadêmica e prática com **PHP, Laravel, JavaScript, HTML, CSS, Bootstrap e MySQL**, além de utilizar ferramentas como **Visual Studio Code, Figma, MySQL Workbench, Git e GitHub** no desenvolvimento e organização dos meus projetos.

Tenho buscado evoluir constantemente na área de tecnologia, aprendendo novas ferramentas, colocando meus conhecimentos em prática e desenvolvendo projetos que contribuam para minha experiência profissional.

Meu **Trabalho de Conclusão de Curso** consiste no desenvolvimento de um sistema web para uma **loja de pratas**, buscando unir uma interface moderna com funcionalidades para clientes e administração da loja.

O sistema foi desenvolvido com uma área de produtos, carrinho de compras, pedidos e gerenciamento administrativo, além de recursos relacionados à acessibilidade e integração com banco de dados.

O projeto representa uma das principais experiências práticas da minha formação em **Desenvolvimento de Sistemas**, permitindo aplicar conhecimentos de desenvolvimento web, banco de dados e organização de sistemas em um projeto completo.
